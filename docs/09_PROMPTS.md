# ASD仕事アシスタント 開発ロードマップ・実装手順書

---

# 1. 開発方針

## 目的

ASD特性を持つユーザーが、
仕事を整理し、次の行動を判断できるAI仕事支援サービスを
最短でリリースする。


---

# 2. 開発優先順位

## 基本方針

以下の順番で開発する。


1. ユーザーが使える状態を作る
2. 価値提供するAI機能を作る
3. 継続利用機能を追加する
4. 収益化機能を追加する


---

# 3. Phase一覧


|Phase|内容|目的|
|-|-|-|
|Phase0|開発環境構築|開発準備|
|Phase1|MVP開発|最低限のサービス完成|
|Phase2|改善機能追加|継続利用向上|
|Phase3|収益化|月5〜10万円達成|
|Phase4|拡張|事業化|
