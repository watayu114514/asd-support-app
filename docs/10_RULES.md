# ASD仕事アシスタント テスト設計書

---

# 1. テスト概要

## 目的

ASD仕事アシスタントが、
ユーザーに安全かつ安定して提供できる品質を確保する。


## 対象

- Frontend
- Backend
- Database
- API
- AI機能
- 決済機能


---

# 2. テスト方針


## 基本方針

以下を重点的に確認する。


- 正常に利用できること
- 入力ミス時に適切なエラーになること
- 不正アクセスを防止できること
- AI利用コストを管理できること


---

# 3. テスト種類


|種類|目的|
|-|-|

|APIテスト|Backend API確認|

|AIテスト|AI回答品質確認|
|負荷テスト|性能確認|

# 4. 認証テスト


## AUTH-001 会員登録


### 正常系

確認:

- 正しい入力で登録できる
- usersに保存される
- ログインできる


### 異常系

確認:

- メール未入力
- 不正メール形式
- パスワード不足
- パスワード不一致
- 重複メール


---

## AUTH-002 ログイン


### 正常系

確認:

- 正しいID/PASSWORDでログインできる


### 異常系

確認:

- 存在しないメール
- パスワード間違い
- 未入力
