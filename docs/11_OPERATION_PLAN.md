# ASD仕事アシスタント 運用設計書

---

# 1. 運用概要

## 目的

ASD仕事アシスタントを安定して提供するため、
サービス公開後の運用方法を定義する。


## 運用対象

- アプリケーション
- データベース
- AI API
- 決済システム
- ユーザー管理
- 障害対応


---

# 2. 運用体制

## 初期フェーズ

担当:

- サーバー管理
- 障害対応
- ユーザー問い合わせ
- AIコスト管理
- アップデート

# 9. 障害対応


## 障害レベル


## Level1

軽微障害


例:

- 一部画面エラー
- 表示崩れ


対応:

次回アップデートで修正


---

## Level2

機能障害


例:

- AI利用不可
- ログイン不可


対応:

原因調査後、緊急修正


---

## Level3

重大障害


例:

- データ消失
- セキュリティ問題


対応:

- サービス停止判断
- 復旧作業
- ユーザー通知
