# ASD仕事アシスタント ユーザーストーリー

## 1. 目的

本サービスを利用するユーザーが、
仕事における困りごとを整理し、
自分で次の行動を判断できる状態を作る。

---

# 2. ペルソナ

## Persona 1

### 名前

田中さん（仮）

### 年齢

28歳

### 職業

会社員（事務職）

### 状況

- PCを使った事務作業が中心
- 入社3年目
- 一人で仕事を任されることが増えている

### 困りごと

- 複数の仕事を同時に頼まれると混乱する
- 優先順位を決めるのが苦手
- 曖昧な指示への対応に困る
- 上司への確認タイミングが分からない

# 3. ユーザーストーリー

# US-001 会員登録

## ユーザー

新規利用者

## 目的

サービスを利用開始したい。

## 行動

1. 登録画面を開く
2. メールアドレスを入力
3. パスワードを入力
4. 登録する

## 完了条件

- アカウントが作成される
- ログインできる

---

3. パスワード入力
4. ログイン

# US-003 今日やる仕事を確認する

# US-004 タスクを登録する
